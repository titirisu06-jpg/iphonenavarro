# Fuentes de imágenes del catálogo

Todos los archivos son renders oficiales descargados desde el CDN de Apple (`store.storeimages.cdn-apple.com`). Se conservaron localmente para evitar enlaces rotos y asegurar que cada ficha muestre el modelo correcto. En algunos assets solo se recortó el lienzo transparente o blanco y se convirtió a WebP para mantener un encuadre consistente y una carga liviana; el producto no fue generado ni retocado.
